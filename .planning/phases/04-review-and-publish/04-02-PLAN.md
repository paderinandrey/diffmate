    - EDITOR unset prints EDITOR is not set and does not create a file.
    - A future-improvement file is that note's text. An empty save does not change the note.
    - i flips limitation_included and never starts a process. No limitation leaves the flag 0.
  </behavior>
  <action>
    save_finding_text writes title and body. If either differs from the stored working copy, it sets decision to edited. If both are unchanged, it leaves the decision as it was. It never updates original_output. save_future_improvement replaces one JSON element of drafts.future_improvements and does not change any finding decision. toggle_limitation flips limitation_included when limitation is not null and returns the new flag. When limitation is null it changes nothing and returns None.

    e on a finding writes the temp file under the cache directory, mode 0700, named by the finding id. The bytes are the title, a newline, a newline, and the body. e on a future improvement writes that note's text only (D-09). Suspend the terminal backend before the process and restore it after. EDITOR unset, or empty, draws "EDITOR is not set" and leaves the row unchanged. There is no fallback editor. Split EDITOR on ASCII whitespace into the program and arguments. Do not process quotes and do not use a shell. A value that cannot be spawned draws that the editor could not be started and leaves the decision unchanged.

    Wait for the process. A non-zero exit leaves the decision unchanged and does not parse the file. Exit 0 with the same bytes leaves the decision unchanged (D-08). Exit 0 with an empty file, or a file that is only whitespace, stores nothing and leaves the decision unchanged. Exit 0 for a finding without a blank line between the title and the body draws "the editor file must be a title, a blank line, and a body" and leaves the decision unchanged. A valid changed finding file calls save_finding_text. A changed future-improvement file calls save_future_improvement. Delete the temp file after the read. i calls toggle_limitation and does not spawn a process (D-09). When toggle returns None, draw "this draft has no limitation".
