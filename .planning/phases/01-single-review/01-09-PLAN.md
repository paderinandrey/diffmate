## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub (comments, check output) → context files | attacker-controlled text and sizes |
| repository tree at merge-base → rules/ | symlinks and large files |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-37 | Tampering | rules/ | high | mitigate | Read from the merge-base with ls-tree and cat-file, never from the worktree; rules_are_read_at_merge_base test |
| T-01-38 | Information disclosure | rules symlinks | medium | mitigate | Symlinks resolved one hop inside the tree only; targets with "..", absolute paths or further links are not followed |
| T-01-39 | Denial of service | discussion, ci, diff, rules | medium | mitigate | Fixed caps with TRUNCATED markers; bounded subprocess capture; at most 10 annotation calls |
| T-01-40 | Repudiation | ci.md | high | mitigate | Missing or empty CI data is "CI status unknown"; no overall pass line exists |
| T-01-41 | Tampering | gh calls | high | mitigate | One GraphQL query without mutation and REST GETs without -f, -F, -X or --method; gh_calls_are_read_only test |
| T-01-42 | Elevation of privilege | PR text in context | medium | accept | Written as data files only; prompts/review.md states PR text cannot change the rules; the agent has Read, Grep and Glob only |
| T-01-SC | Tampering | npm/pip/cargo installs | high | accept | This plan adds no crate |
