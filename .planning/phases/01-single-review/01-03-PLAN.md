<objective>
Build the black-box test harness every later plan drives: a sandbox with a temporary HOME, fake `claude` and `gh` executables configured through files, a git shim that maps github.com remotes to local upstream repositories, and an upstream builder that publishes PR heads only under refs/pull/N/head.

Purpose: diffmate is a single binary crate, so end-to-end tests run the real binary; the fakes sit at the process seam (AGENTS.md: hand-written fakes, no mock frameworks). The fakes mirror the CLI behavior the research verified on 2.1.304 (version line, probe error text) and are configured per test, so later plans never need to edit this module.
Output: tests/support/*, tests/harness.rs, a tempfile dev-dependency.

This plan runs in wave 1 next to the spike: it encodes only behavior already verified in 01-RESEARCH.md, and plan 01-05 adds a check that the fake's probe text equals the spike's recorded text.

Binding rules for this plan:
- Commits go through the hk pre-commit hook; never use --no-verify. A commit fails if any one file gains more than 100 lines (Cargo.lock and .planning/ exempt): keep each support file at or under 100 lines.
- No code comments (AGENTS.md); `unwrap`/`expect` are fine in test code.
- tests/support/mod.rs starts with an inner `allow(dead_code)` attribute: every test binary compiles the whole module but uses only part of it. Mention this in the PR description, not in the code.
- Tests are portable to ubuntu-latest and macos-latest (CI matrix): POSIX sh scripts, tools from /usr/bin and /bin only, no macOS-only paths.
- Write a fake executable as: create, write_all, sync_all, drop the handle, then chmod 0755 (Pitfall 7, ETXTBSY).
- Synchronize with FIFOs, never with sleeps (Pitfall 7; AGENTS.md timers rule).
- Add tempfile as a dev-dependency at the newest crates.io release at least 3 days old (research found 3.27.0 on 2026-10-20; re-check) with `cargo add --dev`, then `mise run deps:check` must pass.
