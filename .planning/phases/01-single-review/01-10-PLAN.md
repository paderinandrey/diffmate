<objective>
Minimal signal handling for a `review` that runs a job (D-03): terminate the agent's process group, record the run failed (interrupted), remove the worktree, store the agent PID and PGID on the run row.

Purpose: the agent runs in its own process group (SPEC Agent contract), so a terminal Ctrl-C reaches only diffmate; without a handler the agent would keep running as an orphan. Full stop-cause semantics are Phase 2.
Output: group-stop logic with a paused-time unit test, cancellation through runner and agent, black-box signal tests.
</objective>
